# 产品上下文 (Product Context)

## 项目存在的意义

为工业自动化场景提供稳定、可靠的上位机软件，充当人机交互界面与下位设备（PLC/仪表/传感器）之间的桥梁。

## 解决的问题

| 问题 | 解决方案 |
|------|---------|
| 设备状态不透明 | 实时数据采集与可视化监控 |
| 手工操作效率低、易出错 | 自动化控制指令下发与流程编排 |
| 故障难追溯 | 报警记录与历史数据存储 |
| 界面与逻辑耦合导致维护困难 | MVVM 分层架构，界面与业务解耦 |

## 系统应如何工作

1. **Views**（WinForms 窗体）只负责界面呈现，通过数据绑定/事件订阅与 ViewModel 交互
2. **ViewModels** 持有界面状态与命令，调用 Services 完成业务
3. **Services** 编排业务逻辑，调用通信层与数据访问层
4. **Communications** 负责与 PLC/串口/网络设备收发数据
5. **DataAccess** 负责数据库读写与历史数据持久化
6. **Models** 为各层共享的纯数据实体

## 用户体验目标

- **实时性**：数据刷新及时，通信响应快
- **可靠性**：通信断线自动重连，异常不崩溃
- **易操作性**：界面清晰，符合工业操作习惯
- **可维护性**：模块解耦，便于功能扩展与排查
